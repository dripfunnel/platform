The theme guard lets a theme do two more honest things. A `t()` key typed as a list of written names (`['hero.one', 'hero.two'] as const`) is accepted, and each name is checked against every language like a written key, so slides, tabs and other repeated parts can loop. CSS transitions and keyframes may animate colours, backgrounds, `box-shadow`, `fill` and `stroke` as well as `transform`, `opacity` and `filter`; properties that move layout stay refused. Themes change nothing.
