Adds `useWishlist`: the signed-in shopper's wishlist for the heart beside Add to cart, a header count and a Wishlist page (`count`, kept in step across every place a page uses it), with the product to add remembered across sign-in, and the option chosen kept on the device so the Wishlist page can add it to the cart. Adds the optional `accountWishlist` route (`/account/wishlist/`), which a theme may map and need not.
