Themes may animate more (#1245). The validator lets through motion's `useScroll`, `stagger`, `animate` and `useAnimate` (in `components/interactive/` only, as before), with `animate` taking only the component's own element, a ref's `current`, `useAnimate`'s `scope.current` or a motion value: a selector string, a list or a value typed `any` is refused under the new rule `code/animate-target`. Besides transform, opacity, filter and colours, CSS Modules, `theme.css` keyframes, Tailwind classes and motion may now animate `background-position`, `background-size`, `box-shadow`, `text-shadow`, `clip-path`, `mask-position`, `mask-size` and `stroke-dashoffset` (motion's `pathLength` and `pathOffset` too), and CSS scroll-driven animation (`animation-timeline` with `scroll()` and `view()`, `scroll-timeline`, `view-timeline`, `animation-range`). Width, height, top, left, right, bottom, inset, margin, padding, gap, font-size, line-height, letter-spacing and grid tracks stay refused, and the message says to use transform or `clip-path` instead.

Core now keeps reduced motion itself. `@dripfunnel/storefront-core/motion` is motion with core's rule (every motion animation ends at once, `useScroll` holds still, `useSpring` follows its source at once while the shopper asks for less motion); the sandbox serves it as `motion` and `motion/react`, and core takes `motion` as an optional peer dependency. `themeStylesheet` now always returns CSS, starting with `reducedMotionCss` (exported from `./guard`), the first layer, which ends every CSS animation, scroll timeline and transition at its last frame under `prefers-reduced-motion`; a store on CSS Modules alone gets that rule and no Tailwind.

Upgrade notes: no theme has to change and no codemod runs; every theme that passed still passes. A theme's own `@media (prefers-reduced-motion: reduce)` rules keep working and may stay, though core's rule now covers them. Under reduced motion a CSS animation shows its last frame, so a reveal whose element starts hidden and ends shown (`animation-fill-mode: both` or `forwards`) is shown at once.
