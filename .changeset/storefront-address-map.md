The address form (checkout and My addresses) shows its map with the form, above the fields, when the store has a map key (#1615). There is no "Pin on map" button any more: a search box above the map lists matching places, and a pin dropped, nudged or chosen sets the point and fills Address, City, State and Postal code (and the country, when the shop sells there), never Name, Phone or Apartment. A new address with nothing to go on opens the map where the browser says the shopper is. The fields follow the warehouse form: Name, Address, Apartment, City, State and PIN code, then Country below PIN code, then Phone. Required fields show the `address.requiredMark` (`*`) after the label and carry `aria-required`, and `TextField` takes `required` and `requiredMark`. The map's message keys `address.map.open`, `move`, `confirm`, `cancel`, `close`, `hide`, `finding` and `remove` are gone (the pin can be moved, not cleared); `address.map.search`, `searchPlaceholder`, `suggestions`, `searchNone`, `searchUnavailable` and `unpinned`, and `address.requiredMark`, are new. Major because every live store's address form changes (docs/code/ARCHITECTURE.md §5), so it reaches a store at its merchant's next publish. No theme file needs to change; its upgrade note is for the release card to add (storefront ARCHITECTURE §7.1).
